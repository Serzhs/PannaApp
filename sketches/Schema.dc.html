cook_notes also points at users, steps and cooks, and recipe_saves at recipes. Those lines are left off so the picture stays readable — the FK rows inside each box are the full truth.
recipes is the hub. Ingredients, equipment, steps, cooks and notes all hang off it and cascade from it.
steps nests into itself. Null parentStepId is a main step; a set one happens during that step. A tree, not a graph, so no cycle can exist.
No foreign key stops a step in recipe A from linking an ingredient in recipe B. Checked in code on write, inside the same transaction.
